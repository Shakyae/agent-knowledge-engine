# PKO Knowledge Operations

- For implementation, architecture, debugging, testing, deployment, or risk changes, retrieve applicable knowledge from `.agents/notes/`, `docs/defensive-patterns/`, `docs/postmortem/`, and `docs/cookbook/` before work.
- Knowledge is organized by kind and lifecycle; use `.agents/skills/knowledge-ops/SKILL.md` for retrieval, candidate, independent review, and publishing procedures.
- Formal knowledge publication requires independent review and explicit human approval; use the designated single publisher and inspect the resulting changes.
- These instructions are soft constraints, not security isolation: ordinary file tools can bypass them and declared identities cannot be independently verified by PKO.
