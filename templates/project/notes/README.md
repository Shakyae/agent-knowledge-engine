# Agent Notes

Agent Notes use the official lifecycle/class path tree:

```text
.agents/notes/{proposed,implemented,rejected}/{feature,bug-fix,simplification,architecture,process,testing}/yyyy-mm-dd-topic-title.md
```

Lifecycle records proposal, shipped decision, or rejection; class records decision kind. Do not add a centralized note index. The official header is exactly three lines:

```markdown
# Agent Note: <title>

Status: proposed | implemented | rejected — <reason for rejected>
```

Notes do not use frontmatter. See the Knowledge-Ops Skill for retrieval and candidate workflow.
